# Actual application evidence

All images here are actual native application windows or VTK framebuffer captures from2026-09-11. No screenshots, drawing inputs, paper boundaries or hand landmarks were fabricated. Runtime captures were generated by the integration checks; native-window captures were taken while operating the real batch-launched application. Existing indexed render inputs are explicitly identified below; they are not held-out sketch tests.
