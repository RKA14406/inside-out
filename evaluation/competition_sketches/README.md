# Real competition sketches

Place 5–10 photographs or rectified webcam captures from different real paper drawings in each folder:

- `heart/` — a simple heart outline
- `car/` — a simple side-view car
- `earth/` — a circle with basic continent/land shapes (a plain circle is not a supported Earth sketch)
- `unknown/` — unrelated scribbles for rejection calibration, if available

These images are calibration/evaluation inputs only. No generated images or fabricated results belong here.
